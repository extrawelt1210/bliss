# Erster Auftrag an Codex

Lies `AGENTS.md`, `docs/PRODUCT.md` und `docs/ROADMAP.md` vollständig.

Erstelle einen kurzen technischen Plan und implementiere dann **nur Phase 1** von Bliss als React-/TypeScript-/Vite-Prototyp.

Nutze die Web Audio API für lokal erzeugtes Brown Noise und Pink Noise. Baue eine visuell ruhige, deutschsprachige, mobil optimierte Oberfläche mit Start, Pause, Stop, Master-Lautstärke und sanftem Fading. Sorge für sichere Audiostandards (Start leise, keine abrupten Änderungen, kein Clipping) und räume Ressourcen zuverlässig auf. Es dürfen keine Netzwerkdienste nötig sein, um Audio abzuspielen.

Füge sinnvolle Unit- und UI-Tests, NPM-Skripte, eine verständliche README und eine kurze manuelle Testcheckliste für macOS und iOS Safari hinzu. Führe die Tests aus; nenne offene Risiken und Einschränkungen.

Wichtig: Der separat bestehende Reflexionsassistent wurde in PyCharm/Codex entwickelt. Das ist **nicht** derselbe Projektordner. Berühre und integriere seinen Code nicht.
